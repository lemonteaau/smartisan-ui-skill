# 真机行为与细节（Smartisan R2 实测）

Figma Kit 只给出静态组件。这份文档补的是**真机上才看得出来的东西**：交互、动画、间距、分隔线、
不同 App 的取色思路。数据来自一台 Smartisan R2（Smartisan OS 8.5.3，1080×2340，density 400，即 2.5x、432dp 宽），
用 `adb exec-out screencap` 截图逐像素取色、`adb shell screenrecord` 录屏后用 ffmpeg 抽 60fps 帧测时长。
参照的应用：设置、音乐、文件管理、应用商店、游戏中心、便签、视频播放器。

> 做出来"像锤子"的关键往往不在颜色，而在这些细节：分段 Tab、按下即变色、没有水波纹、横向推入、
> 弹性回弹、分隔线的长短。Material 组件只要留下一个（线框图标、下划线 Tab、浮起卡片、缩放转场），
> 整页就会有"Material + 锤子混搭"的别扭感。

## 1. 顶栏

| 项 | 实测 |
|---|---|
| 高度 | 48dp（120px） |
| 底部 | **没有细线**；改为一道约 13dp 的柔和投影：紧贴栏底 `#dfdfdf`，向下渐隐到页面底色 |
| 标题 | 居中，17sp 粗体 `#636363` |
| 返回 | 左侧细 **←** 箭头（不是 `<`），`#929292` |
| 右侧操作 | 灰色图标按钮；搜索是**细线**放大镜 |
| 状态栏（系统应用） | 白底，状态栏和顶栏之间有一条很淡的细线 |

### 品牌色顶栏（内容 / 商店类应用）

应用商店（锤子红）、游戏中心（紫）这类内容型应用用**品牌色顶栏**，状态栏同色：

- 渐变 上 `#DA564C` → 下 `#D44A3E`（应用商店），状态栏和栏之间一条半透明亮线。
- 栏内是**内凹的搜索框**：深一档的品牌色（`#BC4438`），圆角约半高，顶部内阴影，底边一条淡亮线；
  放大镜和占位文字是白色约 55% 透明。
- ⚠️ 应用商店栏下方的"射灯"光斑（三个亮点）是**为了体现"商店"特意做的**，不是通用规范，其它应用不要照抄；
  一般用普通柔和投影。

## 2. Tab：分段控件，不是下划线

真机 Tab（应用商店"周排行 / 总排行 / 游戏榜"）是**整宽的分段控件**：

- 外框：圆角 6，0.8dp `#d6d6d6` 描边，底色白 → `#f4f4f4` 渐变；分段之间细竖线同色。
- **选中段是内凹的灰色**：`#b4b4b4 → #a9a9a9` 渐变，顶部约 6dp 的内阴影（黑 16% → 0），左右各约 3dp 的侧内阴影，文字白色粗体。
- 未选中文字 `#8a8a8a` 粗体 14–15sp。高度约 30dp，放在一条浅色带里，上下各 8dp、左右 12dp。
- 段数多（> 5）时可横向滚动；在平板上不要把它拉满全宽，保持手机尺寸居中（约 560dp 以内）。

## 3. 列表、卡片、分隔线、间距

| 场景 | 实测 |
|---|---|
| 列表行高 | 60dp（150px） |
| 卡片页（设置）| 卡片左右 12dp、**卡片间距约 14dp**、圆角 10、0.8dp `#e4e4e4` 描边，下方约 8dp 的淡投影 |
| 卡片内分隔线 | **贯穿卡片全宽**，`#f3f3f3`（非常浅），最后一行下面没有线 |
| 通栏文字列表（音乐、文件管理）| 行 60dp，分隔线 `#f3f3f3` **贯穿全宽** |
| 通栏图文列表（应用商店的应用行）| 分隔线 `#efefef`，**左右各缩进 12dp**，最后一项下面没有线 |
| 分区之间（应用商店）| 一条约 6dp 的带：顶部 `#e4e4e4` 细线，往下内阴影渐变 `#e6e6e6 → #f0f0f0`，底部 `#ebebeb` 细线；**不和分隔线叠用** |
| 分区标题（文件管理"分类浏览"）| 30dp 灰底条，12sp `#9d9d9d`，左 14dp |
| 设置页底纹 | 竖条纹 `#f4f4f4` / `#f2f2f2`，周期约 3.6dp（9px） |
| 列表行图标 | 很浅的实心灰图标，约 `#c8c8c8`，22dp；`>` 箭头粗一点的浅灰 `#b2b2b2` |
| 尾部值（"已关闭"、"无 SIM 卡"）| 13–14sp `#9d9d9d`，紧挨 `>` |

空状态（音乐"暂无歌曲"）：大号浅灰实心图标（约 `#d6d6d6`）+ 粗体灰标题 16sp `#bababa` + 更浅的 12sp 说明。

## 4. 底部导航

白底，顶部细线，高约 54dp。图标是实心浅灰（未选中约 `#c6c6c6`），文字 10sp。
**选中项用该应用的品牌色**（应用商店、音乐都是红色图标 + 红色粗体字），没有指示器背景、没有动画胶囊。
（Figma Kit 里选中是加大的 `#636363` 图标，系统应用实际用品牌色。）

## 5. 按下态（全部"瞬时"，没有渐变动画，没有水波纹）

| 元素 | 按下 | 松开 |
|---|---|---|
| 列表行 / 卡片里的行按钮（"打开应用"）| **整行变蓝 `#5985eb`，文字、图标、`>` 全部变白** | 立即恢复 |
| 灰色凸起按钮（应用商店"安装"）| 渐变**上下反转**：顶部变暗（`#fdfdfd → #f5f5f5`）、底部变亮，像被按进去 | 立即恢复 |
| 实色按钮（红色"卸载"、蓝色主按钮）| 整体深一档（红 `#ec7568 → #e76657`；蓝 `#5b87eb → #4772e6`）| 立即恢复 |
| 顶栏图标按钮 | 图标变深（`#929292 → ≈#5f5f5f`），并弹性放大到 1.33 倍（框架 `playBarIconScaleAnim`，见 `motion.md`）；没有背景高亮 | 弹回 |

细节：快速点击时蓝色只闪一两帧（Android 的按下态最少保留 64ms）；列表行要过 100ms 的点击超时才变蓝，开始滚动就取消；页面推入开始前行已经恢复白色（不要让蓝色"留"到转场里）。完整的按压、转场、手势参数见 `motion.md`。

## 6. 动效

| 动作 | 实测（60fps 抽帧）|
|---|---|
| 页面推入 | ≈300ms。新页面从右侧滑入，**先是空白页（只有底色，左缘一道淡阴影）**，内容在最后约 40% 时淡入；下面的旧页面向左移约 1/3 并淡出 |
| 返回 | 镜像：当前页向右滑出，下面的页面从左侧回来，内容在后段淡入，≈270ms |
| 对话框出现 | ≈250ms，从约 0.85 缩放到 1 并淡入；遮罩同时淡入，最终约 **45% 黑** |
| 滚动到顶 / 底继续拖 | **弹性回弹**（露出底纹），没有 Android 的光晕或拉伸 |
| 底部 Tab 切换 | 立即切换，没有过渡 |
| 开关 | 拨钮滑动约 180–200ms |

## 7. 对话框结构（"警告"确认框）

- 宽约 360dp，圆角 12。
- **标题条**：浅灰 `#f8f8f8` 底，17sp 粗体 `#636363` 居中，下方 0.8dp `#e8e8e8` 分隔线。
- 正文：白底，14–15sp `#656565`，**居中**；可在文字上方放一个图标。
- 底部按钮条：`#f7f7f7`，等宽，竖线分隔；取消 `#636363` 粗体，主操作 `#5e80d0` 粗体，危险操作红色。

## 8. 危险按钮

应用信息页"卸载"：整宽大按钮，红色 `#ec7568`（上浅下深），白色粗体字，按下 `#e76657`。
同页的普通操作（"强行停止 / 打开应用"）是白卡片里的居中文字行，禁用时文字 `#bababa`。

## 9. 一个应用只用一个强调色

各个系统应用各有一个品牌色，并在整个应用里统一使用：应用商店红、游戏中心紫、便签棕、系统应用蓝。
顶栏（如果是品牌栏）、底栏选中项、Tab 选中、主按钮、开关圆点、滑块、勾选、链接、按下的列表行都用这一个颜色。
**不要在同一个应用里一部分用锤子蓝、一部分用品牌色**——这会显得割裂。做第三方应用时建议给用户一个"强调色"设置，
所有强调元素从同一个颜色推导（见 `assets/flutter/smartisan_accent.dart`）。

## 10. 图标风格

系统图标是**实心、圆润**的浅灰字形（设置页的蓝牙、定位、通知、主题等），不是 Material 的线框图标。
但"标记类"图标是线条：`>` 箭头、`✓` 勾、`×`、`+`、搜索放大镜。"更多"是三个较粗的圆点 `•••`。
Flutter 版用 `assets/flutter/glyphs/`（Phosphor Icons 的 fill / bold 字重，MIT）做成的图标字体可以覆盖常用的 160 多个语义。

## 采集方法（可复用）

```bash
adb exec-out screencap -p > shot.png                 # 截图
adb shell screenrecord --time-limit 6 /sdcard/r.mp4  # 录屏，再 adb pull
ffmpeg -i r.mp4 -vf fps=60 f_%03d.png                # 抽帧量动画时长
adb shell input motionevent DOWN x y                 # 按住不放，截图看按下态
```

注意：在锤子上长按文字会触发"大爆炸"，按住后**向下拖**可能触发"一步"（One Step）；
要取消按压，**横向**移开手指再抬起。
